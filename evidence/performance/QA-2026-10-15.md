## Change and result

The 23 fixed corridor acoustic battens now share one mesh, preserving each vertex, normal, grain UV and physical collider. Moving door, cabinet, drawer, folder, cord and collectibles stay separate. Repeated rain frames reuse the last settled camera/billboard transforms and shadow maps; input, ongoing motion, resize, localization and asset changes invalidate them. GPU warmup retains automatic shadow updates; explicit review captures always force fresh shadows. Resolution, antialiasing, 2048px three-cascade daylight, 1024px task shadows, exposure, lights, materials, textures and model topology are unchanged. Full document images and case previews were already loaded on demand and remain so.

Three serial runs per version/profile used installed Edge 155.0.4283.45, fresh storage and disabled HTTP cache on the same local gzip server; 40ms latency, 10Mbps down, 2Mbps up, CPU1x. Desktop 1440×900 DPR1; touch emulation 390×844 DPR1.75 with unchanged room drawing buffer 682×1477. Audio was muted. Before and after series were sequential, not randomized; driver/OS shader caches were not cleared. [Raw before](before.json), [raw after](after.json), [grouped data](summary.json).

These counters include shadow passes. The large reduction is avoided redundant shadow work, not removed model detail. Rain still intentionally updates at at most 24fps (88–90 rendered frames per 4s here). Desktop desk RAF p95 falls from 13.9 to 7.1ms; this is callback cadence, not a measured GPU/display FPS. CPU is synchronous main RAF callback wall time, including render submission; it is not GPU execution time. Textures remain 86. Mobile desk was already idle after settling (zero renders in the 4s sample), so no idle FPS speedup is claimed.

Fresh-shadow captures isolate static batching: desktop desk 879 → 835 calls; corridor 1,044 → 956. Full-refresh desktop desk still submits about 1.14M triangles. Batch bounds alter conservative frustum culling in 13 of 52 poses (-2,100 to +6,600 submitted triangles, worst increase 0.76%); authored topology remains intact. This remaining interaction cost is a risk, not proof of a lag on a physical phone.

## Quality and regressions

[52 matched before/after pairs](VISUAL-REVIEW.md) use exactly matching camera and projection matrices, fixed seed/time and fresh shadows. 35 pairs are pixel-identical; max image RMSE is 0.03191/255 and at most four pixels in any frame differ by more than 8/255. Selected complete native frames were visually inspected: corridor, door back/swing, room lighting, cabinet half-open, drawer open, floor shadow and mobile exterior. Existing completion/52-frame evidence remains intact.

[Shadow reuse validation](shadow-qa.json) compares real WebGL readPixels from cached and forcibly refreshed maps in the same synchronous scene state, during and after camera/lamp/drawer/cabinet/language/resize/exit/reentry changes. A third fresh render is recorded as a numerical control. The stated tolerance is RMSE ≤0.05/255, max channel difference ≤32, with <0.1% changed channels; it detects displaced/stale shadows without demanding bit identity on raster edges.

The previous release's active suites were rerun serially with installed Edge: **17 suites passed**, including 132 ordinary route cases, 12 flows, four no-JS/deep-link edges, five fault injections, and the Edge menu. New shadow validation passed 158 assertions / 76 cached-vs-fresh pixel comparisons (max RMSE 0.04473/255, max channel delta 13; fresh-vs-fresh control max delta 12). [Verification summary](verification.json). Hardware WebGL renderer: NVIDIA RTX 3050 Laptop / ANGLE D3D11; CPU1x emulation does not simulate a phone GPU. [Runner and individual reports](regressions/) retain exit codes, assertions and timings. They cover resume/native downloads, RU/KK/EN and themes, full joinery sweeps, furniture/cord input, case previews/rain, hotspots, collection/cube, context loss/audio/retry, ordinary routes and fault injection, rail focus and bounded hashed-asset retention. Historical scripts tied to superseded designs are not relabeled as current checks. Mobile means emulation. ## Reproduction

From this repository in PowerShell (no environment/secret files needed):

```powershell
New-Item -ItemType Directory -Force qa-private/performance-baseline | Out-Null
git archive --format=tar --output=qa-private/performance-baseline.tar 4b342abb836f817dcabc76e2d99f265c15945c4c docs
tar -xf qa-private/performance-baseline.tar -C qa-private/performance-baseline
npm run build
node scripts/serve-performance.cjs
# In a separate terminal, run one browser job at a time:
node scripts/qa-room-performance.cjs before 3
node scripts/qa-room-performance.cjs after 3
node scripts/qa-room-performance-capture.cjs before
node scripts/qa-room-performance-capture.cjs after
node scripts/qa-room-performance-pixels.cjs
node scripts/qa-room-shadow-cache.cjs
node scripts/qa-room-cold-assets.cjs

```
