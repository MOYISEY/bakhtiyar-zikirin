## Reproduction and limits

Run `npm run build` and serve immutable before/after `docs` trees with the same gzip/cache policy. Use installed Edge, serially. Regression filenames/arguments are in `verification.json`. Then:

```text
node scripts/qa-room-ux.cjs BASE LABEL
SHADOW_QA_OUTPUT=OUT node scripts/qa-room-shadow-cache.cjs BASE
PERF_BASE=BASE PERF_OUTPUT=OUT node scripts/qa-room-performance.cjs VERSION 2
node scripts/qa-room-ux-capture.cjs BASE LABEL
```

Environment-variable syntax above is illustrative; on PowerShell use `$env:NAME='value'`. Camera matrices, complete-frame PNG hashes and public WebP hashes are recorded. Local server uses `/before/` for immutable baseline and `/after/` for candidate; do not compare the older performance baseline from 4b342ab against this UX release by accident.

No physical Android/Safari test is claimed; those were deferred by the user. Both supplied Library screenshot transfers failed because the official helper requires unavailable `os.setxattr` on Windows. No screenshot was installed/read or bypassed; independent live reproduction was explicitly allowed. The Library materialization reference says to stop rather than produce a file without its Library metadata. Consequently these before/after views are independently reproduced, not the exact supplied screenshot camera.
