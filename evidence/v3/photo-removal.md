# Кампус-тур без фотографии

По запросу владельца фотография, браузерная рамка и подпись удалены из кейса Атырау. JPEG удалён из `public/` и `docs/`; новый runtime его не содержит. Исторические отчёты предыдущих аудитов сохраняют прежние результаты и снимки, не выдаются за текущий интерфейс.

Кейс сохраняет название, разбор состояния/навигации, технологии, реальную ссылку на исходники и нативное раскрытие решений. Композиция стала текстовой: крупный заголовок и три колонки пояснений, на мобильном — одна колонка. Новое изображение или вымышленный интерфейс не добавлены.

Проверки этой правки отделены от трёх прежних аудитов: build (TypeScript/Vite), целевой desktop/mobile/reflow 320 px с 200% текста, отсутствие фото и рамки, открытие/закрытие кейса, настоящий переход к GitHub с `opener===null`. Локальные результаты сохраняются в `photo-removal-local.json`; окончательный Pages commit, SHA-256 публичных файлов и целевой live-отчёт — в рабочей области после deploy.
