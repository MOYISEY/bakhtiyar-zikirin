# Локализация, темы и реальные demo-ссылки

Дата: 2026-10-01. Продукт продолжает опубликованный `b74023e91c2c6ac9afb757c65ffac5c7257fbde2`. Предыдущие три независимых аудита сохранены в `evidence/v2`; их покрытие не переносится автоматически на эти изменения.

## Реализовано

- 249 согласованных ключей в каждом из RU / KK / EN: интерфейс, alt/aria/meta, SVG, 3D-текстуры, fallback, динамические шаги и сообщения, PDF/email и небольшой hobby-блок. Технические имена сущностей и бренды сохранены. Внешний продукт на снимках Rowline имеет собственный русский интерфейс, что указано в каждой локали.
- Независимый агент проверил все три словаря и составные фразы; 38 исправлений KK, затем применены замечания RU/EN. [Отчёт перевода](translation-review.md). Это проверка языковой моделью, не подтверждённая редактура носителем.
- Нативные выбор языка и темы, initial system preference, переключение light/dark/system, изменение системного режима, сохранение только двух предпочтений, safe defaults и работа при отказе storage.
- Общие design tokens, цвета SVG и текстур 3D, панели, активные и неактивные кнопки, отключённая кнопка, keyboard focus, hover и color-scheme нативных select.
- Основные реальные demo-кнопки Rowline и нового статического деплоя Атырау; исходники вторичны. [Проверка live-адресов и блокеров](project-live.md).
- По отдельному явному разрешению владельца материализована только публичная версия резюме 0 из Library. На Windows текущему неизменённому helper потребовался адаптер метаданных NTFS вместо отсутствующего `os.setxattr`; сохранённые Library ID и version прочитаны и проверены. PDF: 96 616 байт, одна страница, текст извлечён и страница визуально просмотрена на компьютере. Телефона нет, разрешённая почта есть. [Проверка файла и SHA-256](public-resume-check.json). Для всех языков указано, что PDF на русском.
- Компактный hobby-блок «Красная нить» после профессиональной части: реальная доска сцен, персонажей и улик, проверка зависимостей выводов, безопасный player snapshot и локальные JSON. Сам продукт и его тесты выполнены отдельным автором; здесь проверяется интеграция.

## Выполненные локальные проверки

- `npm run build`: TypeScript и production Vite build прошли. Производственная статика, без dev-only CSS.
- [Матрица Chromium](matrix-local.json): RU / KK / EN × light / dark × desktop 1440×1000 / mobile 390×844 = 12 сценариев. Переходы языка/темы, только разрешённые storage-ключи, reload, skip-link с клавиатуры, все режимы/слои, 3D keyboard/reset/pause, repaint при паузе, сигнал reduced-motion, все три шага brief, сохранение выбранного шага при переводе, четыре disclosures, отсутствие overflow. Axe WCAG 2 A/AA и 2.1 AA с открытыми disclosures, ноль нарушений во всех 12 сценариях. Axe отмечает неполные проверки: они сохранены в JSON и не объявлены автоматически пройденными.
- [Пограничные сценарии](edge-local.json): шесть локалей/тем с принудительным отказом WebGL, no-JS light/dark, system-follow/explicit-override, storage blocked, normal-motion signal с disabled состоянием, отказ основного JS-модуля. В fallback — работающие кнопки и локализованные сообщения. Keyboard focus проверяется реальными Tab / Shift+Tab, а не только программным focus.
- [Firefox и WebKit](engines-local.json): по два целевых сценария (RU/light/desktop и KK/dark/mobile), все режимы/слои/шаги/disclosures и смена настроек. Axe в этих движках не запускался.
- [Контраст токенов](contrast-tokens.json): WCAG relative luminance; текстовые пары ≥ 4,84:1 в light и ≥ 6,63:1 в dark, focus-пары ≥ 3:1. Это дополняет rendered axe и просмотр состояний, не измеряет отдельные пиксели 3D/скриншотов.
- [Тур](tour-live.json): новая публичная Pages-версия реально загружена и проверена на двух viewport; исходники не менялись.
- [Ссылки, PDF и hobby](links-local.json): настоящий download с проверкой всех байтов по SHA-256, mailto href и перехваченный клик без отправки письма, реальные popup-переходы Rowline/Атырау/hobby/code с `opener === null`. Rowline загрузил встроенный пример, Атырау — WebGL-панораму, hobby — реальный интерфейс. Desktop и mobile viewport.
- Limited source scan без находок; это не comprehensive secret detector и не скан всей Git history.

В `screenshots/` сохранены native viewport hero / scene / brief / contact для каждой комбинации. Визуально просмотрены все 12 hero, обе длинные KK brief/contact, резервные 2D и no-JS сцены, тёмные состояния контролов. Остальные снимки сохраняются как доказательство, без утверждения, что каждый пиксель каждого файла отдельно просмотрен. Реальные фото тура не возвращены в портфолио.

## Найденное и исправленное

- No-JS system-dark сначала оставлял светлые SVG-плоскости на тёмной странице. Добавлены media-правила той же палитры; светлая и тёмная версии повторно проверены.
- Высокая специфичность тёмного fill перекрывала wire-режим fallback. Добавлено правило `fill:none`; все шесть fallback-комбинаций прошли.
- В первоначальном тестовом helper проверка неподвижной сцены ошибочно ожидала aria-label «Остановить», хотя reduced-motion правильно показывал «Включить». В другом запуске axe потребовал отдельный browser context. Это ошибки harness, не дефекты продукта; исходные результаты сохранены в `initial-harness-mismatch.json` и `initial-axe-harness-error.json`. Исправленный helper прошёл матрицу.
- Полный обход внешних ссылок сначала пытался кликнуть QA внутри закрытого disclosure. Helper теперь открывает раздел через его summary; первоначальные таймауты сохранены в `initial-links-hidden-disclosure.json`.
- Расширенный helper также ошибочно распознал GitHub `rowline/blob/...` как сам продукт. Live-продукт теперь определяется по точному host/path, исходные результаты — `initial-links-demo-matcher.json`. Продукт при этих таймаутах не менялся.

## Ограничения

Playwright WebKit не является Safari; мобильный viewport/touch не является физическим устройством. Screen reader и системное окно раскрытого native select не проверялись визуально. Проверены клавиатурное поведение, labels, CSS/color-scheme и rendered контрол. KK проверен отдельной языковой моделью; подтверждения носителем нет. Art Portal и NeuralBrief не выданы за live-приложения. Опубликован только отдельно разрешённый публичный PDF и email; телефон и полная приватная версия CV исключены.

[Фактическая публичная проверка](post-deploy.md) содержит 12/12 матрицу, 12/12 edge, обход ссылок и exact-byte доказательство первого runtime release. Финальный commit с доказательствами отдельно проверяется в рабочем каталоге, чтобы не создавать самоссылку commit → отчёт о самом commit.
