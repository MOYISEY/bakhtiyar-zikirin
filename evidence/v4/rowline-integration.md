# Rowline в портфолио

Rowline добавлен первым кейсом и первым проектом в профильном README. Рабочий адрес — https://moyisey.github.io/rowline/, исходники — https://github.com/MOYISEY/rowline. Остальные кейсы сохранены; фото Атырау отсутствует.

Описание сверено с README релиза `773ba67fdafe46c1cc4ada869636439e1f3d8991`: очистка, проверки, ручные исправления/дубликаты, undo, CSV/отчёт/рецепт, добровольное сохранение, точные числовые диапазоны, четыре ограничения входа. Тестовые цифры и метрики не вынесены в карточку. Отчёт QA самого Rowline доступен по отдельной ссылке; его полная матрица не запускается заново для этой интеграции.

Оба PNG сохранены без изменения байтов из публичного release commit: [provenance](rowline-media-provenance.json). Мобильный снимок в кейсе показывает верхнюю часть через CSS crop; это не новый или перерисованный интерфейс. Смысл, действия и ограничения доступны обычным текстом независимо от изображения.

Целевые проверки: build TypeScript/Vite; desktop1440, mobile390, reflow320/200% текста; порядок всех четырёх кейсов и оглавления; загрузка правильного изображения; отсутствие возвращённого фото; раскрытие деталей; три настоящих перехода (demo, код, QA) с `opener===null`; запуск приложения по demo-ссылке. [Локальный журнал](rowline-integration-local.json). Итоговый deploy и live-журнал после публикации сохраняются отдельно в рабочей области, чтобы не создавать self-reference commit.

На длинном element screenshot mobile захват показал фиксированный skip-link поверх кейса. Отдельная проверка после тех же трёх popup-переходов измерила его вне viewport: `:focus=false`, top −90 px, bottom −37 px. На обычном viewport-снимке ссылка не перекрывает CTA; [состояние](native-focus-check.json). Длинный capture не используется как доказательство реального перекрытия интерфейса.
