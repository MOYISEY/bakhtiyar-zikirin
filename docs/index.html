Искусственные данные для примера очистки CSV
SKUstockПроверка
·00124·12Пробелы по краям
001258Готово
Пусто6Нужен SKU

· обозначает пробел в исходном значении.

Правку можно отменить. Экспорт содержит две строки с заполненным SKU.
