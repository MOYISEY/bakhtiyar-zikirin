02
Web / пространственная навигация

Атырау.
Внутри кампуса.

Панорамный тур
по университету.

Переходить между помещениями, не теряя контекст этажа и текущей локации.

Как устроено

Сцены описаны в одном объекте: этаж, название, панорама и переходы. Pannellum показывает изображения; интерфейс синхронизирует миниатюры, этаж и кнопки навигации.

Что видно в коде

Четыре этажа, переходы-hotspots, клавиатурная навигация и ограниченный zoom. Первые миниатюры загружаются сразу, остальные — лениво.

Решения и ограничения +

Навигация как граф

Сцены связаны переходами, а переключение этажа ведёт к его стартовой точке. Активная миниатюра следует за текущей сценой.

Общий источник состояния

Функции обновления интерфейса получают идентификатор сцены. Переход через hotspot также обновляет этаж и миниатюры.

Зависимости

Библиотека Pannellum и шрифты в исходной версии загружаются с CDN. Кейс показывает браузерную навигацию по панорамам.

Модель публикации

Project хранит автора, категорию и теги. ProjectImage связан с публикацией и задаёт порядок изображения. ProjectLike ограничивает повторную пару пользователь–проект.

Разделение сценариев

В views.py поиск объединяет условия по нескольким полям. Создание требует авторизации; редактирование и удаление сравнивают пользователя с автором.

Статус проекта

Учебный репозиторий с Django-моделями и frontend-файлами. В кейсе разобрана структура данных; ссылка на публичное демо не представлена.
