# Бахтияр Зикирин — портфолио

[Публичный сайт](https://moyisey.github.io/bakhtiyar-zikirin/) · [GitHub](https://github.com/MOYISEY/bakhtiyar-zikirin)

Персональное портфолио с кремовым / тёмно-зелёным оформлением: главная, полный каталог и девять самостоятельных страниц проектов. Семь работающих демо показаны собственными свежими снимками, NeuralBrief и Art Portal — явно подписанными схемами по доступным материалам. Картинка и название открывают разбор; отдельная кнопка ведёт в настоящее демо. RU / KK / EN сохраняются при переходах; светлая, тёмная и системная тема; публичное PDF-резюме и разрешённая почта.

Статический Vite / TypeScript / Three.js, локальные шрифты Onest. Авторская 3D-схема загружается после открытия блока в разделе «Подход», поддерживает клавиатуру, reduced motion и 2D fallback. CSV-пример с trim/undo и настоящим экспортом находится на странице Rowline. В каталоге есть фильтры, на страницах проектов — увеличенная галерея с клавиатурой и кнопками для телефона. При недоступном изображении остаются описание и ссылки. Настройки языка и темы — единственные данные в localStorage. GitHub Pages публикует main /docs. Исторические отчёты ниже помечены версиями; [проверки текущих страниц и изображений](evidence/v12/QA.md) описаны отдельно.

## Разработка

```sh
npm ci
npm run dev
npm run build
npm run preview -- --port 5191
```

Сборка сначала генерирует 11 HTML-файлов из `src/content/`, проверяет TypeScript, затем создаёт `docs/`. Отдельные HTML-страницы открываются напрямую, обновляются и работают без JavaScript. Относительные пути поддерживают подпапку Pages, `.nojekyll` сохраняет статические файлы.

## Управление и запасные режимы

- Мышь, два пальца или стрелки вращают 3D; Home и «Сбросить вид» возвращают камеру. Один палец сохраняет прокрутку страницы.
- «Собрать», «Разделить», «Каркас», выбор слоя и «Проследить клик» меняют схему. Пример не обращается к серверу.
- Движение можно остановить; reduced-motion останавливает автоматическое вращение, переходы и smooth scroll. Последний 3D-кадр сохраняется без постоянного RAF.
- Вне экрана, в фоновой вкладке и при bfcache-паузе рендер приостановлен. Ресурсы освобождаются при завершении страницы, потере WebGL и отказе инициализации.
- Без WebGL и при отказе 3D-модуля работает эквивалентная 2D-схема с кнопками. Без JavaScript остаются оформление, тексты, схема, ссылки и нативные раскрывающиеся кейсы; неработающие кнопки скрыты.

[Источники и дизайн-исследование](evidence/v2/research-and-provenance.md) описывают проверенные факты и границы каждого кейса. Фотография кампус-тура удалена из сайта по запросу владельца. Кейс содержит разбор навигации, ссылку на исходники и [настоящий тур](https://moyisey.github.io/atyrau-tour-3d/tour_v2/), опубликованный из существующего статического репозитория без изменения кода.

NeuralBrief — схема процесса по контексту владельца; действующий AI-сервис и публичный деплой не заявлены. Атырау — университетский кампус, не городской тур. Art Portal представлен по доступным Django-фрагментам; полный запускаемый пакет не подтверждён. Опыт и образование сверены с резюме владельца. Метрики, отзывы, клиенты и уровень seniority не добавлялись. После отдельного явного разрешения размещены публичный PDF с опытом/образованием и `b.zikirin@gmail.com`; телефон и полная приватная версия CV не публикуются.

## Два новых инструмента

[Framepack](https://moyisey.github.io/framepack/) готовит размеры JPEG/PNG/WebP для адаптивной вёрстки, без увеличения исходника, и выгружает ZIP с manifest и srcset. [Shapecheck](https://moyisey.github.io/shapecheck/) проверяет JSON-примеры по ограниченному draft-07 контракту и экспортирует запускаемые Node-тесты. Оба компактных кейса переведены на RU/KK/EN и используют настоящие demo/source/QA-ссылки; изображения и заглушки не добавлены. Источники, фактическая интеграционная проверка и её границы сохраняются в [evidence/v8/integration.md](evidence/v8/integration.md).

## Helio

[Helio — солнце и тени города](https://moyisey.github.io/helio/) позволяет выбрать точку на реальной карте и построить модель квартала 300 × 300 м. Реальные контуры зданий, оценочные высоты, тени Three.js и проверка луча по загруженной модели. Солнечные расчёты локальны; карта запрашивается у OpenFreeMap. Открытый горизонт остаётся дополнительным режимом. Полярные даты, DST, JSON/ICS и явное сохранение. [Исходники](https://github.com/MOYISEY/helio), [проверки карты](https://github.com/MOYISEY/helio/blob/main/evidence/live-map-qa.md). Компактная текстовая запись RU/KK/EN, без новых изображений в интерфейсе портфолио. [Проверки интеграции](evidence/v9/integration.md).
