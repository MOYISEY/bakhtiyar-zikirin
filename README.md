# Бахтияр Зикирин — System Atelier

[Публичный сайт](https://moyisey.github.io/bakhtiyar-zikirin/) · [GitHub](https://github.com/MOYISEY/bakhtiyar-zikirin)

System Atelier: авторская композиция, крупная типографика и интерактивная модель приложения. RU / KK / EN и светлая / тёмная / системная тема переключаются нативными контролами. Три слоя — интерфейс, логика и данные — собираются, разделяются и показывают путь запроса. Четыре кейса имеют собственную композицию: рабочий инструмент Rowline, процесс NeuralBrief, текстовый разбор кампус-тура и схема Django-моделей Art Portal.

Статический сайт на Vite, TypeScript и Three.js. Шрифт Onest хранится локально. Бесплатный GitHub Pages публикует `main` → `/docs`; сервер, аналитика и форма отправки не используются.

В `localStorage` сохраняются только язык и выбор темы (`portfolio.preferences.v1`). Начальная тема применяется до загрузки приложения. В режиме «Системная» сайт следует настройке ОС; заблокированное хранилище не мешает переключению в текущем посещении. Перевод включает подписи 3D-текстур, SVG, aria/alt/meta, динамические шаги и сообщения. Настоящие снимки Rowline сохраняют русский интерфейс отдельного продукта; это прямо указано в переводах подписей.

## Разработка

```sh
npm ci
npm run dev
npm run build
npm run preview -- --port 5191
```

Сборка сначала проверяет TypeScript, затем создаёт `docs/`. Относительные пути поддерживают размещение в подпапке Pages, `.nojekyll` сохраняет статические файлы.

## Управление и запасные режимы

- Мышь, два пальца или стрелки вращают 3D; Home и «Сбросить вид» возвращают камеру. Один палец сохраняет прокрутку страницы.
- «Собрать», «Разделить», «Каркас», выбор слоя и «Проследить клик» меняют схему. Пример не обращается к серверу.
- Движение можно остановить; reduced-motion останавливает автоматическое вращение, переходы и smooth scroll. Последний 3D-кадр сохраняется без постоянного RAF.
- Вне экрана, в фоновой вкладке и при bfcache-паузе рендер приостановлен. Ресурсы освобождаются при завершении страницы, потере WebGL и отказе инициализации.
- Без WebGL и при отказе 3D-модуля работает эквивалентная 2D-схема с кнопками. Без JavaScript остаются оформление, тексты, схема, ссылки и нативные раскрывающиеся кейсы; неработающие кнопки скрыты.

Метрики, отзывы, клиенты и уровень seniority не добавлялись. После отдельного явного разрешения размещены публичный PDF с опытом/образованием и `b.zikirin@gmail.com`; телефон и полная приватная версия CV не публикуются.

Helper поддерживает уже установленный cache `qa-private/browsers` и `PLAYWRIGHT_BROWSER_EXECUTABLE_PATH`. До финального результата сохраняются также исходные негативные результаты. Dev-проверки no-JS не считаются проверкой production: Vite dev внедряет CSS через JavaScript.
