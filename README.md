# Бахтияр Зикирин — портфолио

Авторская статическая страница: крупная кириллическая типографика, металлический 3D-этюд на Three.js, интерактивная схема NeuralBrief и выбранные проекты. Стек самого портфолио: Vite, TypeScript, Three.js, локальный Onest.

## Локальный запуск

```sh
npm ci
npm run dev
```

`npm run build` проверяет TypeScript и собирает сайт в `docs/`. Относительные пути позволяют публиковать его в подпапке GitHub Pages. Источник Pages: `main`, `/docs`. Файл `.nojekyll` отключает преобразование статических файлов.

## Интерактивность и доступность

3D-объект вращается мышью; стрелки вращают объект с клавиатуры, Home возвращает вид. На сенсорных экранах один палец прокручивает страницу, два вращают сцену. Кнопки переключают форму, каркас и разборку; движение можно остановить. `prefers-reduced-motion` отключает автоматическое движение и сглаженную прокрутку. Вне экрана и в фоновой вкладке рендеринг приостанавливается. При отсутствии WebGL остаётся статичный вид и весь текст.

Схема NeuralBrief иллюстрирует этапы проекта; это не работающий AI-сервис и не скриншот его интерфейса. Формы с неподключённой отправкой нет. Внешние ссылки ведут в проверенные публичные репозитории и профиль GitHub.

## Проверка фактов

- GitHub-профиль: https://github.com/MOYISEY
- Atyrau Tour: https://github.com/MOYISEY/atyrau-tour-3d — публичное дерево содержит `tour_v2/index.html` и панорамные фотографии.
- Art Portal: https://github.com/MOYISEY/art_portal — README описывает студенческие творческие проекты, Django и PostgreSQL; `package.json` содержит React/Next.js и TypeScript. Конкретных утверждений о состоянии production нет.
- NeuralBrief и стажировка Astana Digital Outsource описаны по профессиональному контексту, переданному владельцем. Публичный репозиторий NeuralBrief не найден среди доступных репозиториев. Метрики, клиенты, отзывы и должностной уровень не добавлялись.

Результаты трёх раундов аудита и браузерных проверок хранятся в `evidence/`.

Для сценарной браузерной проверки: `npm run qa -- <URL> <prefix>`. Нужен Chromium из Playwright (`npx playwright install chromium`) или `PLAYWRIGHT_BROWSER_EXECUTABLE_PATH`. Автоматические клики и мобильная эмуляция не заменяют проверку на физическом телефоне. Исходные уведомления лицензий Three.js и Onest сохранены в `public/licenses/` и включены в сборку.
